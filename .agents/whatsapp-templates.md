# Templates de WhatsApp — KORMAN ETIQUETAS
*Para convertir consultas en pedidos*
*Creado: 19/06/2026*

---

## Contexto de uso
Canal principal: WhatsApp (https://wa.me/5491144756233)
Tono: cercano, argentino, cálido pero profesional. Sin tecnicismos innecesarios.
Objetivo de cada intercambio: llevar al cliente a pedir presupuesto → primera muestra → pedido.

---

## Template 01 — Respuesta inicial (consulta genérica)

**Cuándo usar:** Cuando alguien escribe "hola, quiero información" o similar.

```
¡Hola [nombre]! 👋 Bienvenido a KORMAN ETIQUETAS.

Hacemos etiquetas bordadas personalizadas para marcas de ropa.
Cuéntame un poco más:

→ ¿Tenés un logo o diseño ya listo?
→ ¿Cuántas etiquetas necesitás aproximadamente?
→ ¿Para cuándo las necesitás?

Con eso te armamos el presupuesto enseguida 😊
```

---

## Template 02 — Respuesta a consulta de precio

**Cuándo usar:** "¿Cuánto sale?" sin dar más info.

```
¡Hola! El precio depende del diseño y la cantidad.

Para darte un número concreto necesito saber:
→ ¿Cuántas etiquetas?
→ ¿Con logo/imagen o solo texto?
→ ¿Tenés el diseño listo o necesitás ayuda con eso?

Te respondo con el presupuesto en el día 👌
```

---

## Template 03 — Respuesta a "necesito poca cantidad"

**Cuándo usar:** El cliente dice que necesita pocas o tiene miedo de pedir poco.

```
¡Perfecto, trabajamos pedidos chicos!

Justo eso nos diferencia: no te pedimos que arranques con 500 etiquetas si todavía estás probando tu marca.

Decime cuántas necesitás y te doy el precio sin compromiso 😊
```

---

## Template 04 — Respuesta a "ya compré en China y me fue mal"

**Cuándo usar:** El cliente menciona mala experiencia previa con importados o proveedor anterior.

```
Te entiendo perfectamente, es un dolor muy común.

Con nosotros es diferente: producimos acá en CABA, te mostramos la muestra antes de producir todo, y los plazos son reales.

¿Qué necesitás esta vez? Te cuento cómo trabajamos para que no tengas esa experiencia de nuevo.
```

---

## Template 05 — Envío de presupuesto

**Cuándo usar:** Cuando ya tenemos todos los datos para cotizar.

```
¡Hola [nombre]! Acá va tu presupuesto:

📋 Detalle:
→ [Cantidad] etiquetas bordadas
→ Diseño: [descripción breve]
→ Material: [satén / tafeta / otro]
→ Terminación: [doblada / plana / otra]

💰 Precio: $[monto] + envío (o retiro en [zona])

Tiempo de producción: [X días] desde que aprobás la muestra.

Si querés seguir, el primer paso es que me mandés el logo en buena calidad (PNG o AI) y coordinamos la muestra.

¿Seguimos? 😊
```

---

## Template 06 — Seguimiento (sin respuesta en 2-3 días)

**Cuándo usar:** Cliente que consultó pero no respondió el presupuesto.

```
¡Hola [nombre]! Te escribo para ver si tuviste oportunidad de ver el presupuesto que te mandé.

Si tenés alguna duda o querés ajustar algo, estoy acá 😊

¡Saludos!
```

---

## Template 07 — Cliente que pide muestra primero

**Cuándo usar:** "¿Puedo ver una muestra antes?"

```
¡Claro! Podemos coordinar una muestra de tu diseño antes de producir todo.

Mandame:
→ Tu logo en buena calidad (PNG con fondo transparente o AI)
→ Tamaño aproximado que querés (en cm)
→ Colores

Con eso te cotizo la muestra y arrancamos. Una vez que aprobás, producimos el pedido completo.
```

---

## Template 08 — Cierre post-entrega (para pedir reseña)

**Cuándo usar:** Unos días después de entregar el pedido.

```
¡Hola [nombre]! ¿Cómo quedaron las etiquetas? ¿Todo bien con el pedido?

Si quedaste contento/a, nos ayudaría muchísimo que dejes una reseña o que nos etiquetes cuando uses las etiquetas en tus prendas 🙌

Estamos construyendo la marca y el apoyo de clientes como vos vale oro.

¡Gracias!
```

---

## Notas de uso

- Siempre usar el nombre del cliente si lo tenemos.
- Nunca dar precio sin saber cantidad y diseño — el precio sin contexto siempre parece caro.
- Si el cliente desaparece, hacer un solo seguimiento (Template 06). No insistir más de una vez.
- El emoji justo (1-2 por mensaje) suma calidez sin restar profesionalismo.
