# 🧵 Cuartel General — Etiquetas Bordadas (Negocio de papá)

Este es el centro de operaciones del negocio. Acá guardamos, ordenado y por
escrito, todo lo que vamos a hacer para conseguir más clientes y hacer crecer
la empresa de etiquetas bordadas.

> **Idea clave:** lo que está escrito se puede mejorar. Lo que está en la cabeza,
> se olvida. Por eso todo va acá.

## 📍 Datos del negocio (de un vistazo)

- **Producto:** etiquetas bordadas (marquillas para ropa, nombres, personalizadas)
- **Ubicación:** CABA — Colegiales (Buenos Aires, Argentina)
- **Alcance:** local + envíos al resto del país
- **Clientes principales:** marcas de ropa pequeñas + particulares (regalos / personalizadas)
- **Cómo consigue clientes hoy:** boca a boca (queremos sumar muchos canales más)
