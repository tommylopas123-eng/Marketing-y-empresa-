## 🎨 Logo

- **`logo-perfil.png`** → para la foto de perfil de Instagram/WhatsApp (cuadrado,
  se ve bien en círculo).
- **`logo-horizontal.png`** → para membrete, presupuestos, firma de mail, o como
  marca de agua en las fotos de productos.
- Los `.svg` son los archivos "madre" (editables sin perder calidad). Si algún
  día querés cambiar algo, se editan esos y se vuelven a exportar.

> El logo usa un **borde de puntadas** que imita el hilo del bordado: el logo
> mismo cuenta a qué se dedica el negocio. 🧵

## 🎨 Paleta de colores (usar siempre estos)

| Color | Código | Uso |
|---|---|---|
| Verde profundo | `#0E4D4B` | Color principal (fondos, títulos) |
| Dorado hilo | `#E7C873` | Detalles, acentos |
| Dorado oscuro | `#C99A2E` | Texto sobre fondo claro |
| Crema | `#FDF6E3` | Fondos claros, texto sobre verde |

> Tip: con esos 3-4 colores alcanza. Menos es más. Usar siempre los mismos hace
> que la marca se reconozca.

## ✍️ Tipografías

- **Títulos / nombre:** una serif elegante (tipo Georgia / Playfair Display).
- **Textos / bajadas:** una sans simple (tipo Arial / Montserrat).
- En Canva (gratis) podés buscar "Playfair Display" + "Montserrat".

## ✅ Cómo cargar todo esto (paso a paso)

   botón de contacto y las estadísticas.
